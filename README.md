# File Encryption & Decryption Application

This project was developed as part of the Data Security course and focuses on encrypting and decrypting text files using classical cryptographic algorithms.

The application is a Python-based desktop program that supports:

* Caesar Cipher
* Vigenère Cipher

Users can select an encryption algorithm, enter a key, choose input and output files, and perform encryption or decryption through a graphical user interface built with Tkinter.

The project demonstrates:

* Classical cryptography techniques
* File handling in Python
* GUI development
* Input validation and error handling
* Team collaboration using GitHub

---

# Features

* Caesar Cipher encryption and decryption
* Vigenère Cipher encryption and decryption
* Graphical User Interface (GUI)
* File browsing support
* Save textbox content into `.txt` files
* Input validation
* Error handling and success messages

# Project Structure

## Caesar.py

Implementation of Caesar Cipher encryption and decryption.

## Vigenere.py

Implementation of Vigenère Cipher encryption and decryption.

## Filehandling.py

Handles file browsing, validation, and file management.

## Gui.py

Contains encryption/decryption processing logic and textbox save functionality.

## GuiPjesa2.py

Contains the graphical user interface components and application window.

# Application Workflow

1. Select an encryption algorithm
2. Enter the encryption/decryption key
3. Choose the input file
4. Choose the output file
5. Click Encrypt or Decrypt
6. Save the generated text if needed
